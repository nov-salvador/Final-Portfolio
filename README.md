### Freight Rate Prediction

A machine learning project developed to predict freight rates from shipment and market-related data.

**Technologies:**

- Python
- Pandas
- Scikit-learn
- CatBoost
- XGBoost
- Machine Learning
- Feature Engineering

### Bridge Crack Detection

A computer vision project for detecting bridge cracks using deep learning.

**Technologies:**

- Python
- PyTorch
- ResNet18
- Transfer Learning
- Computer Vision
- FastAPI
- React

The project demonstrates the use of transfer learning to classify images into crack and no-crack categories and exposes the trained model through an API.
